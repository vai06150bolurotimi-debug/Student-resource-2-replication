# Student-resource-2-replication
A complete replication of Student Resource 2 using Python and Pandas.

## Project Description

This repository contains the complete replication of Student Resource 2.
The project applies Python and Pandas techniques to analyse the Roller
Coaster Database dataset.

## Topics and Techniques

- Python
- Pandas
- Data loading
- Data exploration
- Data cleaning
- Missing-value analysis
- Data filtering
- Grouping and aggregation
- Data visualization

## Repository Structure

### `Student_Resource_2_Replication.ipynb`
Contains the complete notebook implementation.



### `Documentation/`
Contains the detailed documentation explaining the project.



## How to Use

1. Download or clone the repository.
2. Open the Jupyter Notebook in Google Colab or JupyterLab.
3. Run the notebook cells sequentially.

## Key Takeaways

The project demonstrates how Python and Pandas can be used to
load, explore, clean, analyse and visualize real-world datasets.
